# BARICA | Frizerski salon

Statička web stranica za GitHub i Cloudflare Pages.

Cloudflare Pages: Build command prazno; output direktorij `.`.

Kontakt podaci: `assets/js/settings.js` i HTML poveznice `tel:` / `mailto:`.

Fotografije za pregled su ilustrativne i nalaze se u `assets/images/`. Prije javne objave zamijeniti ih autentičnim fotografijama ako ih salon dostavi; potvrditi adresu i radno vrijeme.
